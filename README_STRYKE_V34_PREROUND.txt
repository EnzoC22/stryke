STRYKE 3.8 // V34 PRE-ROUND BARRIERS
======================================

Base: V33 Map Bounds Fix.

MECÂNICA NOVA
--------------
A fase de compra agora funciona como preparação tática:
- ambos os times podem se mover durante o countdown;
- Defesa (CT) consegue chegar a A/B e montar o setup antes do round;
- Ataque (T) consegue sair do spawn e se posicionar atrás das barreiras;
- cada time possui limites próprios, criando uma zona neutra antes do contato;
- as barreiras somem automaticamente ao entrar em LIVE;
- armas, faca e granadas continuam sem poder causar ação ofensiva durante freeze.

INTEGRIDADE
-----------
- cliente aplica a colisão para resposta imediata;
- host/servidor também limita posições recebidas durante a preparação;
- bots CT caminham para A/B durante a preparação;
- bots T caminham para pontos de staging atrás das barreiras;
- durante freeze a compra é permitida mesmo depois de o CT sair da base.

VISUAL
------
- T vê barreira laranja;
- CT vê barreira azul;
- a barreira tem painel translúcido + contorno.

PRESERVADO
----------
V33 maps/covers, armas e braços originais, WebSR, performance, sprays, espectador, recoil, dano e economia.
