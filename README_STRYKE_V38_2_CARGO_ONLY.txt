STRYKE 4.2.2 // V38.2 CARGO ONLY
===================================

Base: V38.1 Boot Fix.

Mudança
-------
Cargo passa a ser o único mapa PvP do STRYKE.

- Rodadas: somente Cargo.
- Mata-mata: somente Cargo.
- Saves antigos que apontem para Vanta/Frostline/Kairo são automaticamente corrigidos para Cargo.
- O seletor de mapa PvP mostra apenas Cargo.
- Fallback de criação de partida = Cargo.
- Modo Zumbis permanece independente, com seus mapas próprios.

Todo o restante da V38.1 foi preservado.
