# STRYKE

Competitive tactical FPS 5v5.

## Publicar
Este repositório está configurado para publicar automaticamente no GitHub Pages a cada push na branch `main`.

A build do jogo deve ficar na raiz, com:
- `index.html`
- `assets/`
- `vendor/`
- `_external/`

Depois do upload, aguarde o workflow **Deploy STRYKE to GitHub Pages** terminar.
